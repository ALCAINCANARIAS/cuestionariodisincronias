# cuestionariodisincronias
Disincronías ALCAIN: Formulario de análisis de perfil es una página web que sirve para que el profesorado registre lo que observa en un alumno/a con altas capacidades y obtenga un perfil orientativo de sus disincronías. Funciona en local: según indica el propio formulario, no envía datos a ninguna plataforma.
